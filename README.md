# OneTake public website

GitHub Pages serves the main branch root.

- index.html: product links
- demo.html: public ads, English/Chinese narrated demos, and clearly labelled short-drama storyboard previews
- guide.html: bilingual concise and detailed TestFlight SOPs
- privacy.html / support.html: existing policy and support

All playback is static and requires no viewer account. Media is self-hosted under media/. Only synthetic test-photo capture and fictional AI character previews are included. The short-drama previews are still-image storyboards, not completed moving-actor films. Narration uses Microsoft speech voices.

The new pages reuse style.css and existing Pocketful Studio assets from the privacy page. New page-specific rules are in media.css.
